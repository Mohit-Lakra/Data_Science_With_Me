# 📘 Learning Datascience Libraries with me

Welcome! This repository is designed to be a **perfect place to learn data science libraries** like Numpy, Pandas and Matplotlib in a practical and beginner-friendly way.

## Why this repo is great for learning Data Science Libraries

- ✅ Built for learners who want to understand libraries functions step by step
- ✅ Uses **Jupyter notebooks** to make learning visual and hands-on  
- ✅ Covers concepts with examples you can run and modify  
- ✅ Ideal for beginners and anyone who wants to improve data analysis skills

## Learn by notebooks

The notebooks in this repository help you:

- Read and explore datasets
- Clean and transform data
- Filter, sort, and group information
- Practice real pandas, numpy and matplotlib workflows
